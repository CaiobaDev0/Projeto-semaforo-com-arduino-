Semáforo Inteligente e Cancela Automatizada

Sobre o projeto

Projeto acadêmico desenvolvido em grupo com o objetivo de integrar conceitos de programação, eletrônica e automação utilizando Arduino.

A proposta combina um sistema de sinalização para veículos e pedestres com o controle automatizado de uma cancela por detecção de proximidade.

Funcionalidades propostas

* Controle dos sinais luminosos para veículos.
* Sinalização de travessia para pedestres.
* Acionamento do sistema por botão.
* Alternância entre os modos diurno e noturno utilizando sensor de luminosidade.
* Sinalização sonora por buzzer.
* Detecção de proximidade por sensor ultrassônico.
* Acionamento de cancela por servo motor.

Componentes

* Arduino.
* LEDs para sinalização.
* Botão para pedestres.
* Sensor de luminosidade.
* Buzzer.
* Sensor ultrassônico.
* Servo motor.
* Resistores, fios e conexões necessárias.

Tecnologias e conceitos

* Programação e lógica de controle.
* Arduino e sistemas embarcados introdutórios.
* Integração de sensores e atuadores.
* Automação básica.
* Desenvolvimento colaborativo.
